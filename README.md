# GUI Rock Paper Scissors (Python)

## About

A simple Rock Paper Scissors game built using Python and tkinter.

## Features

* Play against computer
* Random computer choices
* Score tracking
* GUI interface

## Tech Used

* Python
* Tkinter

## How to Run

Run the Python file and choose Rock, Paper, or Scissors.

* Restart button
